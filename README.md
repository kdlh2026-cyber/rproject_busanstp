# 팀 프로젝트
R를 이용한 빅데이터 플랫폼 팀 프로젝트입니다.

## 프로젝트 소개
2023년~2025년 부산 하수처리장의 일별 방류수 수질정보 데이터의 분석 및 시각화

## 분석언어
- R (v4.5.2)

## 개발 환경
- RStudio Desktop  

## 주요 기능
- 주요 패키지 : extrafont, lubridate
- 데이터 전처리/가공 : dplyr,tidyr,stringr,tm
- 데이터 시각화 : ggplot2, trggplot2, plotly,treemap,fmsb,wordcloud, leaflet,hexbin,RColorBrewer
- 웹 대시보드/웹 제작 : shiny

## 데이터 출처
- 공공 데이터 포털 (https://www.data.go.kr)
- 부산환경관리공단 (https://www.beco.or.kr/kor/Main.do)

## 데이터 형태
- CSV

## 데이터 항목
- 사업단(소)
- 날짜
- 하수량
- 생물학적 산소 요구량
- 화학적 산소 요구량
- 부유물질
- 총질소
- 총인
- 수소이온농도
- 위도
- 경도

## 시각화
- 부산시 사업공단 사업소 위치 - [지도 leaflet]
- 2023~2025년 사업소별 일평균 하수처리량 - [막대그래프], [트리맵], [파이그래프]
- 각 사업단 별 수질 지표 - [히트맵]
- 각 연도별 부산 전체 하수량의 월별 변화 추이 - [다중 선 그래프]
- 분기별 화학적 산소 요구량(COD) 변동 - [선 그래프]
- 사업단별 pH 농도 - [박스 그림]
- 각 사업단별 방류수 수질 기준 지표 - [방사형 차트]
